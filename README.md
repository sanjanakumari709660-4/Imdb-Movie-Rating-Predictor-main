# IMDB Movie Rating Prediction

This project predicts IMDB movie ratings using Machine Learning and NLP techniques.

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Features
- Movie rating prediction
- Genre analysis
- Model comparison
- Interactive Streamlit web app

## Run Project

 Step-1: Install libraries:

 Step-2: pip install -r requirements.txt

 Step-3: Run app:- streamlit run app.py
